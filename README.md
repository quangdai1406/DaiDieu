The theme used is a modified version of WordPress default theme "twentythirteen"

## No comments policy
Code in this repo has no comments or docstrings. `python tools/nocomments.py check` lists any that exist, and `python tools/nocomments.py strip` removes them. Enable the pre-commit hook once per clone with `git config core.hooksPath .githooks`. CI runs the same check.
